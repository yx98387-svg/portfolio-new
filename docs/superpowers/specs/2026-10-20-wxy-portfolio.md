# WXY AI Designer Portfolio - Design Spec

## Goal

Create a desktop-first personal portfolio for Wang Xinyuan, an AI designer. The site must feel like a restrained, premium creative studio instead of a template.

## Content source

- Identity: Wang Xinyuan / AI Designer
- Education: Central China Normal University, Visual Communication
- Positioning: Brand visual design, graphic design, AI image creation
- Selected work: Puxian brand campaign; Liu Run countdown campaign; daily brand and IP visuals
- Contact: 13296671260 and 2402800273@qq.com

## Experience structure

1. Hero: full-viewport abstract moving-light background, compact navigation, name, title, call to action.
2. About: portrait-style art panel, biography, contact details, selected work experience.
3. Projects: three oversized visual cards with distinct editorial colour treatments and factual project summaries.
4. Strengths: four concise capability cards.
5. Contact: full-height closing page with oversized invitation and direct contact links.

## Visual direction

- Dark graphite base (#090a0c), warm off-white typography, cool blue-violet accent.
- 1700px maximum content width; generous whitespace; refined display typography paired with a neutral sans-serif.
- Glass is used sparingly. Use fine borders, subtle grain, soft animated light and image-like CSS compositions rather than generic gradients.
- Art cards are deliberately identified as conceptual visual placeholders until real project assets are supplied.

## Technical constraints

- React + Vite.
- Desktop-first; support smaller screens without compromising the primary PC composition.
- No external image/video dependency is required for the first runnable build.
- Provide navigation anchors and a mailto CTA.
